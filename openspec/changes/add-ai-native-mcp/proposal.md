## Why

Operators and integration teams need to use EdiSpark’s exchange and validation evidence from their assistants. The first release supports investigation and deterministic previews.

## What Changes

- Define the product strategy across exception resolution, mapping, partner onboarding, and integration development.
- Add an opt-in MCP endpoint with exchange searches and traces, route context, mapping previews, and outbound readiness checks.

## Capabilities

### New Capabilities

- `edi-mcp` exposes tenant-scoped EDI evidence and previews to approved MCP clients.

### Modified Capabilities

None.

## Impact

Spring Boot composition, OAuth, Exchange queries, mapping and readiness previews, and local demo verification.
